All maps here were designed for AssaultCube 1.3.0.2 Lockdown Edition. They likely won't work in any prior version, nor AssaultCube Reloaded since ACR is based off an earlier build of AC.
These maps are free to edit and adjust, BUT only with credits to my original work.

mir_ancient: Based on "Tomb" from TS1. Deathmatch focused map but has support for all modes.
mir_barfight: A small bar in the nowhere west. Deathmatch map with other mode support if you're crazy enough.
mir_buildsite: The CLA have taken over a construction site and the RVSF have responded. Intended for team Survivor and OSOK modes. 
mir_canyon: TOSOK map with other gamemode support thrown in.
mir_corner: A street corner in an abandoned district. Intended for CTF.
mir_creek: Very open map with support for all gamemodes. My first map ever!
mir_duel: Exclusively designed for 1v1 TOSOK gameplay. Spin around and take yer opponent's head off!
mir_goldrush: Basic CTF map in an underground mine.
mir_gunrange: Good for testing your shooting skills solo. Otherwise designed for CTF.
mir_rooftops: Similarly open to mir_creek. All modes supported.
